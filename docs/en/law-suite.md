# Law suite: laws × subjects

:jp: [日本語版](../ja/law-suite.md)

`tests/laws/` runs each virtual subject of experiment-io through a procedure from the literature and judges the record against values reported in the original papers (cited in each test file). This page is generated by `.venv/bin/python tests/laws/law_table.py` from the same checks the tests assert on (ten seeds each; values are the median [min, max] over seeds); `tests/laws/test_law_table.py` fails when it is out of date.

- **predicts**: the subject's source says the law holds. A check that fails is a test failure, except a check marked *xfail*: it is recorded as a strict expected failure with the reason given.
- **control**: the constant-rate Poisson responder, which must fail the law (judged by each law's control tests; the law's checks are shown for reference).
- **out of scope**: not run; the subject has no equation that applies to the procedure.

`RaCSubject` (Shahan & Craig, 2017) and `MprSubject` (Killeen, 1994) use the published parameter values, not values fitted to these tests. In the ratio-versus-interval law, `MprSubject` uses the published rat VR values for the ratio member and the published pigeon FI values for the interval member; no population with both sets was found.

  - F4 (xfail): a constant run rate puts the peak in any of the last five segments, not mostly in the last three

Reasons:

- `ScallopSubject` (out of scope): its rate ramp is tied to a fixed interval (ramp_s)
- `SpacedRespondingSubject` (out of scope): built for the DRL example (spaced responding); no law in this suite tests it
- `IrtCopyistSubject` (predicts): emits the inter-response times that were reinforced (Tanno & Silberberg, 2012)

  - V3 (xfail): not predicted: the ratio stays at 1.26-1.57 from 100 to 3,550 reinforcers/h and falls below 1 only at VR 200 (ratio strain), so it never converges from above

  - M1 (xfail): undermatches: sensitivity 0.84 [0.73, 0.88] with ten sessions per condition and 0.85 [0.82, 0.89] with thirty. Cause: the values weight every session since the option was first reinforced, so the earlier conditions stay in them. The value equations alone, given the arranged rates in the same order, give 0.85 and 0.89; without the changeover delay a new subject for each condition gives 1.02 [0.97, 1.04]. With the changeover delay a new subject for each condition cannot be measured: on VI 108-s : VI 540-s it stops earning reinforcers on the lean key
- `MprSubject` (out of scope): single-operandum subject; the law needs two operanda
